# ♻️ EcoSort AI

**EcoSort AI** is a smart waste management platform that uses **AI and data-driven technologies** to improve waste collection, classification, recycling, and route management.

### ✨ Features
- 🤖 AI-based waste classification
- 🚛 Smart waste collection
- 🗺️ Route management
- ♻️ Recycling management
- 📊 Analytics dashboard
- 🔐 User & admin management

### 🛠️ Technologies
**HTML | CSS | JavaScript | Python | Flask | Supabase | Machine Learning**
